# Please “Don’t” Help

A satirical obstacle-race book by Kyle Keech, starring Muscle Hero and the Paper Hero Club.

Live page: https://mh-hq-cinematic.github.io/Please-dont-help/

- `index.html`: the book page (support buttons, QR code, cast, course map, race photos, videos)
- `preview.png`: the image shown when the link is shared
- `qrcode.js`: QR code generator (qrcode-generator 1.4.4, MIT license)
